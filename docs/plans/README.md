# docs/plans/

The plan of the work in hand, and the plans of work finished.

`plan.md` is the live one: what is being done now, step by step, with a
status header. It is written before the code and kept up as the steps are
done, so that a session interrupted can be picked up rather than worked out
again. When it is complete it is archived here as
`AAAA-MM-JJ-HHMM-slug.md` and `plan.md` goes.

None of it is history -- the history of the work is in the GitHub issues.
So the folder is gitignored, this file excepted.
